# Портфолио видеомонтажёра

Статичный сайт на чистых HTML, CSS и JavaScript. Без сборки, сервера, базы данных и платных сервисов.
Текст сайта на английском, эта инструкция на русском.

## Что внутри

```
portfolio/
├── README.md              ← эта инструкция (на хостинг не загружается)
└── site/                  ← ВСЁ, ЧТО ПУБЛИКУЕТСЯ (загружайте именно эту папку)
    ├── index.html         ← структура страницы, title и описание для поиска
    ├── _headers           ← настройки заголовков для Cloudflare Pages
    ├── css/style.css      ← оформление (цвета и размеры в блоке :root вверху)
    ├── js/content.js      ← ВСЕ ТЕКСТЫ, ВИДЕО, ССЫЛКИ И КОНТАКТЫ (главный файл для правок)
    ├── js/main.js         ← логика сайта (обычно не трогаете)
    └── assets/
        ├── favicon.svg    ← иконка вкладки
        ├── images/        ← обложки, ваше фото, картинка для превью ссылки
        └── videos/        ← ваши MP4-файлы (если не используете YouTube)
```

## 1. Запуск на своём компьютере

Установка ничего не требует. Выберите любой способ.

**Способ А. Двойной клик.** Откройте `site/index.html` в браузере. Сайт откроется, но
**YouTube-ролики при открытии файла напрямую не воспроизводятся** (YouTube не принимает запросы
со страниц `file://`, появится ошибка плеера). MP4-файлы с вашего диска при этом работают.

**Способ Б. Локальный сервер (рекомендуется).** Так сайт ведёт себя так же, как после публикации.

```bash
cd portfolio/site
python3 -m http.server 8000
```

Откройте `http://localhost:8000`. Остановить сервер: `Ctrl + C`.
(На Windows команда может называться `python` или `py`.)

Альтернативы: расширение **Live Server** для VS Code (правая кнопка на `index.html`, Open with Live Server)
или `npx serve site`, если установлен Node.js.

После правки файла просто обновите страницу в браузере (`Ctrl/Cmd + Shift + R`).

## 2. Как менять содержимое

Почти всё меняется в одном файле: **`site/js/content.js`**. В нём есть комментарии у каждого блока.
Сохраняйте кавычки `""` и запятые `,` как в образце.

| Что нужно изменить | Где |
|---|---|
| Имя, профессия, короткое описание в первом экране | `name`, `role`, `tagline` |
| Строка «Open to new projects» | `availability` (`show: false` скрывает её) |
| Кнопка Showreel в первом экране | `showreel` (пустой `id`/`src` скрывает кнопку) |
| Telegram и Email | `contacts.telegram`, `contacts.email` |
| Ссылки на соцсети под кнопками контактов | `contacts.socials` |
| Текст «Обо мне», принципы работы, фото, список программ | `about` |
| Список услуг | `services` |
| Названия и подписи категорий | `categories` |
| Видео | `projects` |

Строки со словом `PLACEHOLDER` и все названия проектов вида «Short-form project title» это
заготовки. Реальных достижений, клиентов и цифр на сайте нет: добавляйте только то, что соответствует действительности.

**Вне `content.js`:**

- **Заголовок вкладки, описание для Google и превью ссылки в Telegram/соцсетях:** блок `<head>` в `site/index.html`.
  Для превью положите картинку 1200×630 в `site/assets/images/og-image.jpg`, раскомментируйте строку `og:image`
  и впишите свой домен.
- **Цвета:** переменные в начале `site/css/style.css`. Акцентный красный: `--red` (заливки и кнопки) и `--red-text` (красный текст).
- **Шрифт:** Archivo с Google Fonts (бесплатно). Если нужно без внешних запросов, скачайте шрифт, положите в
  `site/assets/` и подключите через `@font-face` вместо ссылки в `index.html`.

## 3. Как добавить видео

Каждый ролик это один блок `{ ... }` в списке `projects`. Скопируйте существующий блок, чтобы добавить проект, или удалите, чтобы убрать.

```js
{ category: "short",            // "short", "youtube" или "other"
  featured: false,              // true = большой блок «Selected work» вверху
  title: "Название ролика",
  note: "Что вы делали в этом проекте",   // можно оставить ""
  poster: "",                   // своя обложка, например "assets/images/cover1.jpg"
  video: { type: "youtube", id: "https://youtube.com/shorts/XXXXXXXXXXX" } }
```

**Три источника видео:**

1. **YouTube** (самый простой и бесплатный вариант): `{ type: "youtube", id: "..." }`.
   Можно вставить ID или целую ссылку, включая ссылки на Shorts. Обложка подтягивается автоматически.
   Ролик может быть «Доступ по ссылке» (unlisted), но в YouTube Studio должно быть разрешено встраивание.
2. **Vimeo:** `{ type: "vimeo", id: "123456789" }`. Добавьте `poster`, обложка автоматически не загружается.
3. **Свой MP4-файл:** положите файл в `site/assets/videos/` и укажите `{ type: "file", src: "assets/videos/my-video.mp4" }`.
   Если `poster` не указан, в качестве обложки показывается первый кадр.

**Формат:** вертикальное видео (9:16) для `short`, горизонтальное (16:9) для остальных. Это можно переопределить
полем `format: "vertical"` или `format: "horizontal"`.

**Пока видео нет:** оставьте `id: ""` или `src: ""`. Карточка покажет заготовку «Your video here».

**Куда попадёт ролик:** с `featured: true` в большой блок «Selected work» (играет прямо в карточке),
с `featured: false` в свою категорию ниже (открывается в окне поверх страницы). Один ролик не показывается дважды.
Пустая категория скрывается автоматически.

**TikTok и Instagram:** у них нет простого бесплатного встраивания. Загрузите ролик как YouTube Shorts (можно unlisted)
или выложите MP4 на сайт.

### Важно про размер MP4

У Cloudflare Pages **лимит 25 MiB на один файл**, а при загрузке перетаскиванием в панели управления
не больше 1000 файлов. Бесплатный план поддерживает до 20 000 файлов на сайт. Файлы больше 25 MiB загрузить не получится.
Сжать ролик можно бесплатной программой [ffmpeg](https://ffmpeg.org):

```bash
# вертикальное видео ~720x1280, ориентировочно 10-20 МБ на минуту
ffmpeg -i input.mp4 -c:v libx264 -crf 24 -preset slow -vf "scale=-2:1280" \
  -c:a aac -b:a 128k -movflags +faststart output.mp4
```

Для длинных роликов и всего, что не влезает в 25 MiB, используйте YouTube или Vimeo.

## 4. Бесплатная публикация на Cloudflare Pages

Нужен бесплатный аккаунт на [cloudflare.com](https://dash.cloudflare.com/sign-up).

### Вариант 1. Перетаскиванием папки (проще всего)

1. Войдите в [панель Cloudflare](https://dash.cloudflare.com) и откройте **Workers & Pages**.
2. Нажмите **Create application**, затем **Get started** и **Drag and drop your files**.
   (Меню Cloudflare иногда меняет названия. Ищите создание Pages-проекта с загрузкой файлов, «Direct Upload».)
3. Введите имя проекта. Оно станет адресом `имя.pages.dev`.
4. Перетащите в окно **папку `site`** (или её ZIP-архив). Проверьте, что `index.html` лежит в корне загружаемого.
5. Нажмите **Deploy site**. Через несколько секунд сайт будет доступен по адресу `https://имя.pages.dev`.

**Как обновить сайт:** внесите правки, откройте проект, нажмите **Create a new deployment** и загрузите папку заново.

### Вариант 2. Через GitHub (автоматическое обновление при каждой правке)

1. Создайте репозиторий на GitHub и загрузите в него содержимое папки `portfolio`.
2. В Cloudflare: **Workers & Pages**, **Create application**, **Pages**, **Import an existing Git repository**.
3. Выберите репозиторий. Параметры сборки: Framework preset `None`, Build command пустое,
   **Build output directory `site`**.
4. После каждого `git push` сайт обновляется сам.

### Вариант 3. Из терминала (если установлен Node.js)

```bash
npx wrangler pages deploy site --project-name=my-portfolio
```

### Свой домен

В проекте откройте **Custom domains**, **Set up a domain**, введите домен и следуйте подсказкам.
Домен покупается отдельно, у Cloudflare Pages бесплатного домена, кроме `.pages.dev`, нет.

- [ ] Видео добавлены (или оставлены заготовки на время)
- [ ] Удалены или изменены услуги, которых вы не оказываете

- [ ] Каждый MP4 весит меньше 25 MiB
- [ ] Сайт проверен в телефоне (откройте адрес `.pages.dev` в мобильном браузере)

## 6. Частые вопросы

**YouTube-ролик показывает ошибку плеера.** Проверьте, что в YouTube Studio включено встраивание, ID указан верно
и сайт открыт через `http://localhost` или `https://`, а не двойным кликом по файлу.

**Обложка не появилась.** Укажите свою через `poster: "assets/images/cover.jpg"`. Для YouTube это нужно редко.

**Имя слишком длинное.** Размер шрифта подбирается автоматически, но для очень длинных имён
лучше использовать короткий вариант.

**Как убрать красную «шкалу монтажа» в первом экране.** Удалите блок `<div class="timeline" ...>` в `index.html`.
Это чисто декоративный элемент.
